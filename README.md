# whenes-portfolio

Build publicável do portfólio de Whenes Oliveira, servido pela Vercel.

**Não edite este repositório.** O conteúdo é gerado automaticamente a partir de
[whenes/github-pages-resume](https://github.com/whenes/github-pages-resume) pela
Action `sync-vercel-build` a cada merge na branch principal de lá; qualquer
mudança feita aqui é sobrescrita no próximo sync.

## Conteúdo

- `index.html`: portfólio em português do Brasil (padrão)
- `en/index.html`: versão em inglês
- `components.html`: referência do design system (dev components)
- `assets/`: CSS e JS compartilhados
- `vercel.json`: configuração da Vercel (site estático; `/en` redireciona para `/en/` para os caminhos relativos resolverem)

## Vercel

Projeto importado deste repositório com Framework Preset **Other**, sem comando
de build e com diretório de saída na raiz.
