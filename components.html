Typography

Inter · Unbounded · JetBrains Mono

Inter stays Steply's working face. Unbounded is reserved for short display lines: the name, section titles, the contact line. JetBrains Mono appears only where the content is code, a date range, a ref or a flag key.

Language switch

.lang-switch

One static page per language, linked to each other. The current language carries aria-current="true"; each link names its language with hreflang, lang and an aria-label in that language. Following a link keeps a deep link such as #job-totvs. Scripts read their interface strings from i18n.js by <html lang>.

Migration case

.flag-case · role="switch"

A case study the reader operates. Flip the flag and the request path moves from the legacy services to the modern ones, the way the TOTVS portal validated new implementations before switching users. Add data-flag-case; both states' switch label and status line live in the markup (data-flag-state="off|on"), so each language page carries its own copy; the script only toggles them.
